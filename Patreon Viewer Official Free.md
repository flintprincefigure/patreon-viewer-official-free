## 🎨 Access the Art. Skip the Paywall.

**Patreon Viewer Official Free** is a sleek, third-party web client designed to unlock and aggregate publicly available posts from your favorite Patreon creators. We understand the frustration of finding a creator you love, only to hit a locked post. This tool acts as a seamless bridge, allowing you to view images, text updates, and embedded media that are otherwise hidden behind tier subscriptions.

It’s built with a focus on speed, privacy, and a beautiful user interface. You aren't just getting a raw list of links; you're getting a fully rendered feed that mirrors the native Patreon experience. No ads, no trackers, just the content you want to see.

> 💡 **Why use this viewer?** Because discovering new artists shouldn't require a credit card. Use this tool to preview creator pages, browse public archives, and decide which creators truly deserve your financial support.

## 🚀 Quick Start

> **Three steps. Two minutes. No account required.**

### 1️⃣ Access the web app
Click the **Launch Viewer** button at the top of this README. No installation is needed for the web version.

### 2️⃣ Paste a creator's link
Copy the URL of the Patreon creator you want to view (e.g., `patreon.com/creatorname`) and paste it into the search bar.

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🕷️ **Scraper Engine** | Fetches public JSON data and bypasses basic restrictions | `Puppeteer` / `Axios` |
| 🎨 **Frontend UI** | Renders the feed with infinite scrolling and media viewers | `React` + `Vite` |
| ⚡ **Caching Layer** | Caches frequently requested creator pages | `Redis` |
| 🛡️ **Proxy Network** | Rotates IPs to prevent rate limits | Custom Proxy Pool |

</div>

The app is designed to be completely serverless for personal use, but includes an optional Node.js backend for handling heavy scraping and bypassing IP blocks.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this legal?</b></summary>

This tool is an aggregator for **publicly accessible** content. It does not bypass paywalls for private or locked posts. It simply formats public data. However, scraping may violate Patreon's Terms of Service. Use this tool for **educational and preview purposes only**.
</details>

<details>
<summary><b>Why can't I see some locked posts?</b></summary>

If a post is strictly locked to paying subscribers and the media is not publicly hosted on the CDN, the tool cannot magically bypass the encryption. It only unlocks what is technically publicly available.
</details>

<details>
<summary><b>Do I need to log in with my Patreon account?</b></summary>

Absolutely not. We strongly advise against entering your credentials anywhere except the official Patreon website. This tool requires no login and operates completely anonymously.
</details>

<details>
<summary><b>How often is the tool updated?</b></summary>

Patreon frequently updates its anti-scraping measures. We push updates to our scraper engine regularly. If the tool stops working, check back in a few days for a patch.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include the creator's URL and a screenshot of the error you encountered.
</details>
